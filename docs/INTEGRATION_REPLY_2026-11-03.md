# 2026-11-03 카메라 미디어 회신

카메라 미디어 범위인 LC-1·LC-2·LC-3·LC-4·LC-6을 작업했습니다. LC-5는 합의대로 오케스트레이션/라이다 설정 확인 범위로 제외했습니다. 기존 응답 계약을 유지하며 상세 규칙은 [추가 계약](INTEGRATION_HANDOFF_2026-11-03.md)에 정리했습니다.

현재 문서는 구현 검증 중인 초안입니다. 운영 적용 버전·SD 전환·재시작과 실제 백엔드 검증 결과는 완료 후 이 문서와 VALIDATION.md에 반영합니다.

| 항목 | 반영 내용 | 확인 범위 |
|---|---|---|
| LC-1 | SD 장치/마운트 보호, 복사·검증·복구 도구, 별도 미디어 전용 마운트 | SSD 원본 보존. UUID·장치·권한·해시·카탈로그·기존 경로·재시작 검증 |
| LC-2 | 전체 저장 예산, MP4 작업 공간 확보, 실제 출력 크기 검증, 보관·삭제 규칙 명시 | 다운로드 직후 삭제 없음. 접근 만료와 실제 정리 구분.30일분 용량 보장 아님 |
| LC-3 | 실제 파일 정보 영구 저장/우선 조회, 교체 무효화·구형 보완·중복 검사 제한 | 생성 경로·재시작·128개 초과·교체·검사 중 변경·삭제·만료·선택 정보 저장 실패 |
| LC-4 | 실제 수신 근거에 따른 조각 경계 처리, 짧은 손실 보존, HLS/파일/JSON 처리의 이벤트 루프 분리 | 전후 관찰 구간의 완성 프레임·새 조각 경계·첫/반복 HLS 응답으로 비교. 과거 실제 손실을 복구됐다고 표시하지 않음 |
| LC-6 | 기존 썸네일/시각 미지원 유지, 작업 한도·공간 오류 계약 구분 | `EXPORT_CAPACITY_EXCEEDED`는 미발생. 실제 사용하는 `SERVICE_BUSY`/`INSUFFICIENT_STORAGE` 등 명시 |

썸네일은 선택 기능으로 현재 unsupported/null, 프레임 생성 시각은 입력 미지원으로 false/null이며 서버 수신 시각만 제공합니다. 미디어 API와 브라우저 인증의 기존 담당 경계는 유지합니다. 백엔드가 업무 흐름과 화면 연결을 검증할 수 있도록 실제 적용 결과를 별도로 회신합니다. 이메일·메신저 발송은 하지 않았습니다.

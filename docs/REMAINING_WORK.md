# 남은 운영 검증

2026-09-20 기준 HTTP MJPEG와 백엔드 제어 API, 이벤트 MP4, 삭제·만료 처리를 구현했다. 규격은 BACKEND_API_CONTRACT.md, 로컬 검증 범위는 VALIDATION.md를 참조한다.

- 백엔드의 기존 WHEP 중개를 HTTP MJPEG로 변경하고 실제 대시보드에서 연동 검증한다.
- 라즈베리파이 5와 실제 웹캠의 1080p 30fps 입력으로 프레임 크기·수신 지연·버퍼 디스크 I/O·인코딩 시간을 측정한다.
- 카메라 수, 동시 시청자 수, 이벤트 빈도에 맞춰 MAX_BUFFER_BYTES와 MAX_CLIP_JOBS, 디스크 용량을 정한다.
- 대상 브라우저에서 MJPEG, H.264/MP4, 탐색 및 다운로드를 검증한다.
- 운영 TLS, 엣지 인증 토큰, 볼륨 권한, 프록시 버퍼링·연결 타임아웃을 배포 환경에서 검증한다.
- Windows 파일 잠금과 Linux unlink 동작 차이가 있으므로 운영 OS에서 조회 중 삭제 동작을 확인한다.
- 프로세스 종료 복구는 테스트하되 전원 장애·파일시스템 손상·장시간 디스크 고갈은 추가 운영 시험 대상으로 둔다.
- 완료 파일은 보관 기간으로 정리하지만 전체 저장소 하드 쿼터와 오래된 메타데이터 자동 정리는 아직 제공하지 않는다.

로컬 자동 테스트 통과는 실제 장비·백엔드·브라우저 연동 및 성능 보장을 의미하지 않는다.
